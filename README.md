# TOEFL AI Examiner

A single-page TOEFL practice web app for GitHub Pages.

## Files

- `index.html` - Main app
- `key.txt` - Your Gemini API key

## Setup

1. Replace the text inside `key.txt` with your Gemini API key.
2. Push both files to a GitHub repository.
3. Go to GitHub repository settings:
   - Settings → Pages
   - Deploy from branch
   - Branch: `main`
   - Folder: `/root`
4. Open your GitHub Pages URL.

## Important

This is a personal-use app. On GitHub Pages, `key.txt` is public. Anyone with your site link can technically view the key.

## Features

- Reading practice with passage questions
- Listening practice with lecture/conversation scripts and text-to-speech playback
- Speaking practice with browser microphone transcription
- Writing practice with integrated and academic discussion prompts
- AI examiner feedback using Gemini
- TOEFL-style timers

## Browser Notes

- Microphone transcription works best in Chrome or Edge.
- Safari/iPhone speech recognition support may be limited.
